# Security Policy

This repository is a local portfolio prototype and does not operate a hosted service. Do not submit real
customer, applicant, account, or credit data to examples or issue reports.

Report suspected vulnerabilities privately to the repository owner rather than publishing exploit or
secret details in a public issue. Rotate any credential accidentally committed to a fork immediately;
removing it from Git history is not sufficient.

The demonstration model is not a security, authorization, identity, or lending-decision control. The
repository audit script checks common accidental secret patterns and oversized files, but it is not a
replacement for a dedicated secret scanner or organizational security review.
